## Notes

- **DaVinci Resolve** is freeware from Blackmagic Design (not open source). The free download is on their site and usually requires a short registration form. Studio is a separate paid product.
- **Obsidian** is free for personal use; Sync / Publish / commercial licenses are optional paid add-ons.
- **Scratch** also runs in the browser at https://scratch.mit.edu/ — the download page is the official desktop / offline app.
- **Godot** current line is Godot 4. Use the download page for your OS; C# / .NET builds are listed separately.
- Always download from the official domains above. Avoid random “free download” sites.
